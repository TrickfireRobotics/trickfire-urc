---
title: Object Detection
description: Object detection on the rover.
---

The object detection for the rover runs using YOLO26 provided by Ultralytics. The model is
pre-trained to detect a wide variety of objects, but is not finetuned to train anything specific at the moment.

Object detection lives in the object_detection package and currently contains a script to detect all
objects found in the results of the models scan and draw bounding boxes around them with labels and
confidence ratings.

The object detection node subscribes and publishes to the following topics to the following topics.

| Topic                                            | Message Type        | What                                                         |
| ------------------------------------------------ | -------------------- | ----------------------------------------------------------- |                            |
| /zed/zed_node/rgb/color/rect/image               | Image                | RGB image that object detection runs on                     |
| /image_annotated                                 | Image                | Annotated RGB image that contains bounding boxes and labels |
| /detections                                      | Detection2DArray     | 2D array containg data about the objects detected           |
| /image_annotated/comporessed                     | CompressedImage      | Compressed version of the annotated image                   |
